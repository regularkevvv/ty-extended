# Examples

- `monty/` — the minimal Monty plugin: one hook, one type patch, a few lines of
    Python. Start here.
- `minidjango/` — a realistic ORM plugin implemented twice, once in Python for
    the `monty` runtime and once in Rust for `wasm`, over an identical project.
    Covers class transforms, project indexing, cross-symbol contributions,
    virtual types, settings claims, and plugin diagnostics.
