# ty-extended repository

## Development

Parts of `.github/workflows/release.yml` are generated by cargo-dist from `dist-workspace.toml`. Before editing the release workflow, check whether the relevant section is generated. Prefer changing `dist-workspace.toml` or the referenced reusable workflow instead of editing generated YAML. After modifying cargo-dist configuration, regenerate the workflow with the cargo-dist version pinned in `dist-workspace.toml` and inspect the resulting diff to ensure the change will survive future regenerations.

## Security reviews

For reviews of this repository's GitHub automation, CI, and release process, use the [GitHub repository threat model](agents/references/repository-threat-model.md). Ruff parsing and notebook crates are pinned upstream registry dependencies; plugin host, protocol and SDK sources live in `crates/` in this repository. Include the lockfile and those sources when tracing release artifacts. ty-extended does not build its semantic checker: official Astral ty is a separate runtime dependency.
